# BharatSaarthi-
BharatSaarthi  is a voice and text-based assistant that helps citizens discover relevant government schemes through multilingual profiling, instant eligibility checks, document guidance, and state-aware recommendations.

### AI-Powered Government Scheme Navigator for Every Citizen

> **Making government benefits easier to discover, understand, and access.**

## 🎯 Problem Statement

Millions of eligible citizens struggle to access government schemes because information is scattered across multiple portals, official language is complex, and vulnerable groups often face difficulties understanding eligibility and document requirements.

**Core Gap:** Information exists, but finding the right scheme at the right time remains difficult.

## 💡 Solution

**BharatSaarthi AI** is a voice and text-based assistant that understands a citizen's:

* Language
* Age
* Occupation
* Income
* Location
* Needs
* Social category

It then recommends relevant government schemes with eligibility explanations, document checklists, and links to official application sources.

## 🚀 Key Features

* 🎙️ Voice-based interaction
* 💬 Text-based scheme search
* 🌐 Hindi, English, Hinglish & regional-language support
* 👤 Natural-language user profiling
* ✅ Instant eligibility results
* 📊 Eligibility confidence scores
* 📄 Exact document checklist
* 📍 State/region-aware recommendations
* 🔗 Direct official scheme/application links
* 🧠 AI-generated plain-language explanations
* 🔄 Hybrid retrieval and rules-based processing
* 🛡️ Cached scheme fallback for unreliable connectivity

## 📌 Project Disclaimer

BharatSaarthi AI is a prototype for helping users discover and understand government schemes. Eligibility information should be verified against the relevant official government source before applying.
